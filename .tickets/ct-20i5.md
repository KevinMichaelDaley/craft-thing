# Rebind fluid descriptors across incompatible compute pipeline layouts

DC_VK_VALIDATE=1 on the full bulk_phase_gpu_tests suite reports VUID-vkCmdDispatch-None-08600 during dc_gpu_fluid_step: a shader dispatch uses set 0 without a compatible bound descriptor set after switching compute pipeline layouts. The isolated bulk-phase-only validation smoke is clean after widening the common push range; this is a separate water/fluid binding path.

## Acceptance Criteria

Run the full bulk_phase_gpu_tests under the Khronos validation layer on Xephyr :92 with zero descriptor-set compatibility or unbound-set VUIDs. Add a focused regression for the water/fluid pipeline transition and keep normal make test passing.
