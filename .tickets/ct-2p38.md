# Add multiplayer-safe player identity, action and extensible RPG state

Implement independent player instances, action intents, action/animation state and data-driven stat, attribute and ability identifiers/values. Establish interfaces needed by movement, targeting, inventory and per-player pixel state.

## Acceptance Criteria

Independent state for at least two players with no singleton ownership leakage. Extensible registered/namespaced attributes/stats/abilities and validated lookups without a hardcoded ruleset. Deterministic elapsed-time frame selection for 6-frame walk, 8-frame chew and 4-frame cast; handle invalid inputs, action transitions and timing boundaries. Headless C11 tests compile and fail before implementation, then pass. API and ownership documented.
